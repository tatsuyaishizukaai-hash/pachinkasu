# パチンコ繁盛記

釘と設定、イベント日、店づくりで客を呼ぶ、ドット絵のパチンコ屋経営ゲームです。iPhoneのホーム画面に追加すると、全画面のアプリとして遊べます。

## 遊ぶ

公開URL：（GitHub Pagesで公開したら、ここに書きます）

### iPhoneのホーム画面に追加する

1. Safariで公開URLを開く
2. 下の「共有」ボタンを押す
3. 「ホーム画面に追加」を選ぶ

ホーム画面のアイコンから開くと全画面で動きます。一度開けば、電波がないところでも遊べます。画面は横向きで遊ぶ作りです（縦に持っていても自動で横向きの表示になります）。

### セーブを移す

セーブは開いている場所ごとに別々に保存されます（Claudeのアーティファクト版とホーム画面アプリ版は別）。進み具合を移すときは：

1. 移す元のメニューで「セーブの引っ越し」→「セーブをコピー」
2. 移す先のメニューで「セーブの引っ越し」→ 欄に貼り付けて「読み込む」

## 開発メモ

- ソースは `src/` にあります。ゲーム本体は `data.js` → `state.js` → `market.js` → `sim.js` → `features.js` → `render.js` → `audio.js` → `ui.js` → `main.js` の順に `src/template.html` に埋め込まれます。
- ビルド：`node src/build-app.js`
  - ルートの `index.html` と `sw.js`（ホーム画面アプリ版）を作り直します。`sw.js` のバージョンはビルドのたびに変わるので、公開後は開き直すだけで新しい版に入れ替わります。
  - `dist/artifact.html`（アーティファクト版）も作ります（`dist/` はコミットしません）。
- アイコン：`python3 src/make-icons.py`（Playwright と Noto Sans CJK JP が必要）
- アプリ版では `window.APP_MODE` が `true` になります。
- 手元で確かめる：`python3 -m http.server 8000` を動かして http://localhost:8000/ を開く。
